# 🧹 Limpiador y Automatizador de Datos en Python

Un script automatizado desarrollado en Python utilizando la librería **Pandas** para procesar, normalizar y limpiar archivos CSV/Excel con inconsistencias de formato.

---

## 🛠️ ¿Qué problema resuelve?

En entornos corporativos y de negocio, los archivos de datos suelen contener errores comunes que impiden su análisis inmediato. Este script automatiza la resolución de:
* **Duplicados:** Eliminación de registros repetidos.
* **Formato de texto:** Normalización de nombres (capitalización) y corrección de espacios innecesarios.
* **Consistencia de correos:** Conversión a minúsculas y eliminación de caracteres extraños.
* **Estandarización de fechas:** Homogeneización de múltiples formatos de fecha al estándar internacional `YYYY-MM-DD`.
